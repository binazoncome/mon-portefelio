À propos

Je m'appelle ZINSOU COME BINAZON. Je suis un apprenant débutant en développement web au Bénin.

Mon apprentissage porte principalement sur la création de pages web avec HTML5, CSS3 et JavaScript.

Je m'intéresse également au responsive design, à l'accessibilité et à l'écoconception web.

Mes compétences

Les principales compétences développées pendant mon apprentissage.

HTML5

Création de structures web avec HTML5 et utilisation des balises sémantiques.

CSS3

Mise en forme des pages web, typographie, couleurs, Flexbox, Grid et responsive design.

JavaScript

Création d'interactions simples et validation des données saisies par l'utilisateur.

Responsive Design

Adaptation des pages web aux ordinateurs, tablettes et téléphones.

Accessibilité web

Utilisation de bonnes pratiques pour rendre les pages plus accessibles aux utilisateurs.

Écoconception web

Utilisation de pratiques permettant de limiter le poids et les ressources inutiles d'un site web.

VS Code

Utilisation de Visual Studio Code pour écrire, organiser et modifier le code.

DevTools

Utilisation des outils du navigateur pour tester et corriger les pages web.
